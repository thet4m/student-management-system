Student Management System in C
A lightweight, console-based Student Management System built in C to practice fundamental programming concepts, data structures, and CLI design.

Features
Add Student: Input student details (ID, Name with full spaces, Age, GPA, Email).

Display Students: View a formatted list of all registered students.

Search Student: Locate a specific student quickly using their unique ID.

Delete Student: Remove a student record from memory by ID.

Clear All: Reset the student database.

Concepts and Technologies Used
Language: C / C++

Data Structure: struct, Fixed-size Arrays

Core Logic: Control structures, loops, standard I/O streams, basic array manipulation algorithms.

How to Run
Clone the repository:
git clone https://github.com/thet4m/student-management-system.git

Open and run:

Visual Studio: Double-click student-manager.slnx and press Ctrl + F5.

Command Line (G++):
g++ student-manager/student-manager.cpp -o student_manager
./student_manager
